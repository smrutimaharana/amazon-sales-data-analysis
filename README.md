# Amazon Sales Data Analysis

## Project Overview
This project analyzes Amazon sales data using Microsoft Excel to understand sales performance, profitability, order volume, and state-wise business performance.

## Objective
The main objective of this project is to analyze sales data and present meaningful insights through Excel-based data analysis and visualization.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization

## Work Performed
- Organized and analyzed Amazon sales data.
- Created Pivot Tables to summarize sales, profit, and order information.
- Compared sales performance across different states.
- Created charts to visualize key business metrics.
- Identified patterns and trends from the analyzed data.

## Key Analysis
The analysis focuses on:
- Total Sales
- Total Profit
- Number of Orders
- State-wise performance
- Sales and profit comparison
